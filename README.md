# BioInspired Studio

A Streamlit biomimicry engineering idea explorer.

## Run locallys
1. Install Python 3.10+.
2. Open a terminal in this project folder.
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

## Deploy
Push all project files to a GitHub repository, then deploy on Streamlit Community Cloud.
Main file path: `app.py`.

## Note
Recommendations use TF-IDF text similarity on a small curated data library. Similarity is not engineering validation.
